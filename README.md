# 손톱 (sontop)

손끝이 입으로 올라가는 순간을 카메라로 잡아내서 즉시 경고하는 웹 앱입니다.
영상은 브라우저 밖으로 나가지 않고, 서버도 계정도 없습니다.

```
npm test          # 판정 로직 테스트
npm run dev       # http://localhost:8080
npm run dev -- --https   # 폰에서 테스트할 때 (https://<내부IP>:8443)
```

**배포된 주소: https://trash-traco.github.io/sontop/**
`main`에 푸시하면 테스트가 돌고, 통과하면 자동으로 배포됩니다.

| | 웹 / PWA | iOS 네이티브 (사이드로드) |
|---|---|---|
| 만드는 비용 | 파일 몇 개, 지금 바로 | Mac + Xcode 필요 |
| 설치 | 주소 열고 "홈 화면에 추가" | 서명·프로비저닝 필요 |

| 카메라 | ✅ (HTTPS 필수) | ✅ |
| 화면 꺼진 채 백그라운드 감시 | ❌ | 카메라는 ❌, **Apple Watch 손목 모션은 ✅** |

그래서 이 저장소는 **웹 먼저** 갑니다. 책상에 앉아 있을 때 쓰는 용도라면 어차피 기기가 앞에 놓여 있어서
카메라 방식이 제일 잘 맞고, 설치·만료·심사 문제가 전부 사라집니다.
네이티브가 필요해지는 지점과 사이드로드 방법은 [docs/ios.md](docs/ios.md)에 정리해 뒀습니다.

## 어떻게 감지하나

1. `getUserMedia`로 전면 카메라를 엽니다.
2. MediaPipe **Face Landmarker**가 입 주변 점 10개와 양 광대(얼굴 너비)를 줍니다.
3. MediaPipe **Hand Landmarker**가 양손 손가락 끝 5개씩을 줍니다.
4. `거리 = 가장 가까운 손끝 ↔ 가장 가까운 입 점` 을 **얼굴 너비로 나눕니다.**
   이 정규화 덕분에 카메라에 가까이 앉든 멀리 앉든 같은 기준이 유지됩니다.
5. 이 값이 임계값 아래로 **일정 시간 유지되면** 경고합니다.

한 프레임 스쳤다고 울리면 못 씁니다. 그래서 판정에 세 겹을 뒀습니다
(전부 `src/detector.js`의 `BiteTracker`, 테스트는 `test/tracker.test.js`):

- **유지 시간(dwell)** — 기본 0.9초. 턱 괴다가 스친 손은 걸러집니다.
- **흔들림 허용** — 유지 구간의 60%만 가까우면 인정. 손가락이 얼굴에 겹쳐 추적이 한두 프레임 끊겨도 놓치지 않습니다.
- **히스테리시스** — 한 번 울리면 임계값의 1.35배를 벗어나야 해제. 경계선에서 삐삐거리지 않습니다.

얼굴 모델은 3프레임에 한 번만 돌립니다. 머리는 손보다 훨씬 느리게 움직이니 매 프레임 돌릴 이유가 없고,
그만큼 프레임이 나옵니다. 전체 루프는 18fps를 목표로 합니다.

## 보정 (처음 한 번은 꼭)

설정에서 **랜드마크 표시**를 켜고, HUD의 `거리` 숫자를 보면서 맞추세요.

1. 평소 자세로 앉습니다 → 보통 `0.8` 이상.
2. 턱을 괴어 봅니다 → 보통 `0.3 ~ 0.4`.
3. 손톱 뜯는 자세를 취합니다 → 보통 `0.10 ~ 0.18`.

2번과 3번 사이에 **민감도**를 놓으면 됩니다. 기본값 `0.22`가 대부분 맞지만,
오탐이 잦으면 내리고 놓치면 올리세요. 유지 시간은 반응 속도와 오탐의 맞교환입니다 (0초 = 즉시).

## 남 앞에서 쓸 때 (독서실·카페·사무실)

눈에 띄는 요소가 둘 있는데 각각 끌 수 있습니다.

**1. 화면에 뜨는 내 얼굴 — `가리기` 버튼 (단축키 `H`)**

영상 위에 검은 판을 덮습니다. 화면에는 숨 쉬듯 깜빡이는 점 하나와 HUD만 남습니다.
**감지는 그대로 돕니다.** `display:none`으로 숨기면 브라우저가 프레임 전달을 멈춰
감지가 조용히 죽어버리기 때문에, 영상은 계속 그려 두고 그 위를 덮는 방식입니다.
상태는 저장돼서 다음에도 가린 채로 시작합니다.

**2. 경고할 때 번쩍이는 빨간 화면 — 설정의 `경고 표시 → 은은하게`**

전체 화면 대신 가장자리에 얇은 빨간 테두리와 작은 알약만 뜹니다. 옆자리에서는
거의 안 보이고 본인만 알아챕니다.

소리는 `설정 → 소리 경고`로 끄면 됩니다. 다만 iOS는 `navigator.vibrate`를 지원하지
않아서 소리를 끄면 시각 경고만 남습니다. **이어폰을 꽂으면 소리 경고가 가장 확실하면서도
남한테 안 들립니다** — 독서실이라면 이 조합을 권합니다.

## 경고 방식

**경고는 손을 뗄 때까지 유지됩니다.** 한 번 울리고 마는 게 아니라, 손끝이 입에서
떨어질 때까지 화면 경고와 소리가 계속됩니다. 무시하고 계속 뜯으면 계속 울립니다.

소리(비프 0.9초 간격) · 음성("손 내려", 2.8초 간격) · 진동(안드로이드) ·
화면 경고(전체/은은하게) · 다른 탭에 있을 때 시스템 알림. 전부 설정에서 끄고 켭니다.

소리와 음성은 독립입니다. **둘 다 켜면 비프와 음성이 겹쳐 울립니다** — 음성만
쓰려면 `소리 경고`를 끄세요.

음성은 브라우저 내장 TTS(`speechSynthesis`)라 별도 설치나 네트워크가 필요 없습니다.
다만 걸리는 데가 있어서 이렇게 처리했습니다:

- **iOS는 사용자 제스처 안에서 한 번은 말해 봐야** 이후 호출을 허용합니다. 시작 버튼을
  누를 때 무음 발화로 잠금을 풉니다. 안 그러면 조용히 무시됩니다.
- **`getVoices()`는 처음에 비어 있습니다.** `voiceschanged`로 한국어 음성을 잡고,
  없으면 기본 음성으로 떨어집니다(영어 음성이 읽으면 발음이 뭉개집니다).
- Chrome에서 `speaking`이 true로 박혀 음성이 영구히 멎는 버그가 있어, 두 주기 넘게
  물려 있으면 강제로 해제합니다.

경고 화면을 탭하면 **그 회차의 소리만** 꺼집니다. 화면 경고는 손을 뗄 때까지 남고,
손을 떼면 음소거도 풀립니다. 오탐이 났을 때 조용히 넘어가되, 진짜일 때 못 끄게
하려는 절충입니다.

`재알림 간격`은 이제 횟수·진동·음성에만 걸립니다. 짧게 여러 번 뜯어도 한 번으로
세지만, 화면과 소리는 그때그때 계속 뜹니다. `설정 → 경고 테스트`로 미리 들어 보세요.

날짜별 횟수를 `localStorage`에 쌓아서 최근 7일 그래프를 보여 줍니다. 기기 안에만 남습니다.

## 알아 둘 제약

- **카메라를 보고 있어야 합니다.** 얼굴이나 손이 프레임을 벗어나면 감시가 멈추고 HUD가 `미감지`로 바뀝니다.
- **브라우저가 앞에 떠 있어야 합니다.** 탭이 백그라운드로 가면 브라우저가 타이머를 조입니다.
  Screen Wake Lock으로 화면 꺼짐은 막지만(iOS 16.4+ 지원), 다른 앱으로 넘어가면 감시는 멈춥니다.
- **2D 거리입니다.** 손이 얼굴 *앞*을 지나가면 실제로는 멀어도 가깝게 보입니다. 유지 시간이 이걸 상당 부분 걸러 줍니다.
- 어두우면 손 추적이 먼저 무너집니다. 얼굴보다 손이 먼저 안 잡힙니다.
- 첫 실행 때 모델 약 11MB를 받습니다. 그 다음부터는 서비스 워커가 캐시해서 오프라인에서도 뜹니다.

## 프라이버시

프레임은 카메라 → WASM → 버림. 어디로도 올라가지 않고 저장도 안 됩니다.
네트워크를 쓰는 건 최초 1회 모델 다운로드뿐이라, 그 뒤엔 비행기 모드로도 동작합니다.
완전히 자급자족하고 싶으면 `src/config.js` 주석대로 런타임과 모델을 같이 호스팅하면 됩니다.
